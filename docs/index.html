Key Features

Built for Faster, Hassle-Free Rail Bookings

Designed with the latest automation protocols directly interfacing with Bangladesh Railway's official system.

🚆

Multi-Train Auto-Booking

Single-API route coverage enables you to target multiple trains (e.g. Subarna, Sonar Bangla, Mohanagar) simultaneously without restarting or resetting your search.

💺

Multi-Coach Flexibility

Book up to 4 tickets across any coaches on the train. The smart algorithm accommodates your group even when seats are scattered across different coaches.

⏱️

Departure-Time Monitoring

No artificial 60-minute time limits. Monitoring runs continuously until the train's scheduled departure time, maximizing your chance to catch released seats.

🔐

Google SMS Retriever API

Safely auto-fills railway OTP codes without requiring sensitive SMS reading permissions. Fully complies with Google Play & APKPure security policies.

💳

Dynamic Cloud Credit Wallet

Live database sync with Firestore. You only spend 1 credit when an auto-book reservation locks seats and triggers the railway OTP.

🌐

Bilingual & Sleek Dark Mode

Toggle between Bangla and English effortlessly. Designed with an elegant, battery-saving dark interface and smooth queue waiting animations.
